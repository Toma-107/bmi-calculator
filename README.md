# BMI Calculator

A simple and responsive BMI (Body Mass Index) Calculator built using HTML, CSS, and JavaScript.

**Live demo:** https://toma-107.github.io/bmi-calculator/

## About The Project

This project helps users calculate their Body Mass Index (BMI) based on their height and weight.

It also displays the BMI category and provides a live preview while entering the values.

## Features

- Calculate BMI using height and weight.
- Live BMI preview.
- Display BMI result.
- Show health status based on BMI.
- Input validation.
- Responsive design.
- Modern UI with gradient background.
- Smooth hover and animation effects.

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)

## BMI Formula

BMI is calculated using the following formula:

`BMI = Weight (kg) / Height (m)²`

## BMI Categories

| BMI Range | Category |
|---|---|
| Below 18.5 | Underweight |
| 18.5 – 24.9 | Normal Weight |
| 25 – 29.9 | Overweight |
| 30 or above | Obesity |

*These are general adult BMI categories.*

## How To Run

1. Clone this repository:

   `git clone YOUR_REPOSITORY_URL`

2. Open the project folder in VS Code.

3. Open `index.html` in your browser.

4. Enter your height and weight.

5. Click the Calculate BMI button.
